# Agent documentation

This tree contains requirements and internal working references.
It is separate from the [user guide](../README.md).

- Topic specifications in this directory record confirmed contracts, constraints, and decisions.
- [Maintenance references](maintenance/architecture.md) describe repository implementation and checks.
- [Publishing setup](maintenance/publishing.md) describes prototype NuGet releases and account configuration.
- [Validation records](history/validation-xlsx-stage3.md) and [measurements](history/measurements/README.md) retain internal evidence.

Human documentation outside this tree describes current library use.
The [roadmap](../roadmap.md) contains unimplemented future plans.
Keep human guides free of phase history, commit IDs, test-result logs, and implementation chronology.
